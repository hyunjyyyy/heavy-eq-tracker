## 몰랐던 것 → 알게 된 것
- 수집 API가 202라 부하 도구가 재는 응답 시간은 Kafka에 넣기까지다 → 판정 지연은 서버 지표로 재야 한다.
- 시드를 고정해도 `Random` 하나를 스레드끼리 나눠 쓰면 순서가 달라져 경로가 바뀐다 → 장비마다 따로 만든다.
- PowerShell 5.1은 파이프로 넘기는 글자를 ASCII로 바꾼다 → SQL 파일의 한글 주석이 깨져 문장이 엉뚱하게 실행된다. `$OutputEncoding`을 UTF-8로.
- 비밀번호 변수가 비면 `-p`만 남아 mysql이 비밀번호를 묻고, 파이프로 들어온 SQL 첫 줄을 비밀번호로 읽는다 → 새 터미널에선 `.env` 읽기부터.
- 30초에 300이 아니라 290 → 시작을 흩은 만큼 + "보내기 후 1초 쉬기"라 주기가 1초보다 조금 길다.

- 시뮬레이터가 잴 것 = 보낸 수 → 응답 코드별 수(202·429·4xx·5xx)와 202까지 걸린 시간도. 서버는 판정 지연을 lag·처리 시간·`recordedAt`→판정 끝으로 나눠 잰다.
